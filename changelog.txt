UNRELEASED

  - fix(security): REST/MCP Origin guard rejects non-loopback Origin (curl
    with no Origin still works); wrapper bind is ownership-safe on re-bind
    (silent mint while bound is 403); wrapper injects POINTER_TEXT only
    (ignores response JSON pointer); roster capped at 256 agents
    (roster_full); in_flight redelivery uses the same batch byte/count caps
    and remaining counts leftover unacked; bind_wrapper wakes unbound
    /wake waiters; sqlite failures map to storage_error (500) instead of
    storage_full pending:-1; graceful shutdown exits non-zero if the mailbox
    wipe fails.

  - fix(wake): wrapper bindings are ownership-tokened — POST
    /agents/{agent}/wrapper returns a wakeId token (or accepts one) and
    DELETE requires it, so a stale wrapper exiting after a replacement can no
    longer clear the newer binding; mentischat --agent now awaits its bind
    task before unbinding. register with nudgeTransport none clears the wake
    session token. Canceled long-poll waiters (dropped connections) no longer
    consume the single wake signal per send. Parked unbound /wake/{id}
    sessions are globally capped (64) and their map entries drain on expiry.
    The wrapper bind route accepts an empty POST body as {}. Shutdown logs at
    error level if the mailbox-discard transaction fails instead of silently
    swallowing it. Migration recreates idx_roster_wake_id on databases that
    have the column but lost the index.

  - fix(wake): inject pointer text and submit key separately; default submit
    is CR (Enter) so OpenCode submits instead of treating LF as a newline.

  - feat(cli): `mentischat opencode` / `mentischat grok` launch a harness with
    idle wake; `mentischat serve` (or bare `mentischat`) starts the daemon.
    `--harness` is an explicit alias. `mentis-wake` remains as a legacy binary.

  - feat(wake): wake-session auto-bind — `mentischat opencode` sets
    MENTISCHAT_WAKE_ID on the child; agent passes wakeId on first register to
    bind wrapper transport. New REST: GET/DELETE /wake/{wake_id}. Legacy
    `--agent` mode unchanged.

  - remove(nudge): in-daemon AppleScript doorbell removed; idle wake is
    mentis-wake only. Historical v1 design documented in NUDGE-V1-TERMINAL.md.
    register no longer accepts windowTitleMatch; nudgeWindow is always null;
    default nudgeTransport is none; terminal is a deprecated wire alias for none.

  - feat(wake): universal PTY wrapper `mentis-wake` — a thin client-side
    adapter between Terminal and any harness (OpenCode, Claude Code, Codex,
    shells). It long-polls the daemon's read-only nudge peek endpoint and
    injects the pointer constant without focus theft or AppleScript. New REST:
    GET /nudge/{agent}?wait_ms= (side-effect-free long-poll; no promote, no
    ack, no lastSeen), POST/DELETE /agents/{agent}/wrapper (bind/clear the
    wrapper transport). register accepts optional nudgeTransport
    ('terminal' | 'wrapper' | 'none'); roster gains nudge_transport column.
    One transport per agent. macOS + Linux v1.
  - feat(shutdown): graceful SIGTERM/SIGINT now discards the roster and all
    undelivered mail in one transaction (bulk deregister), so a deliberate
    restart starts clean. A crash (no shutdown) still preserves the roster and
    mail for recovery.

  - feat(nudge): doorbell runs inside the mentischat process. register binds
    a Terminal.app window (optional windowTitleMatch, else unique title /
    front window) onto the roster row as nudgeWindow; deregister clears it.
    send notifies an idle recipient; the worker injects the pointer without
    calling check_inbox. Sidecar nudge.sh / targets.json removed.
  - feat(core): mentischat daemon on the cloudllm_mcp backbone — one loopback
    process serving MCP Streamable HTTP at /mcp plus REST, backed by sqlite
    pending mail (WAL). Five tools: register, deregister, send_message,
    check_inbox (blocking pull, 0-30000ms), list_agents. At-least-once
    delivery: unacked in-flight rows redeliver until acked; bounded batches
    (8 msgs / 16 KiB) keep TUI tool results truncation-safe; caps fail fast
    (64 KiB body, 1024/recipient, 8192 global, 8 waiters/name). Roster and
    undelivered mail survive crash/restart; parked waiters do not. Domain
    errors map to isError:true content blocks carrying contract JSON; REST
    mirrors every tool with frozen 200-success semantics and typed error
    codes.
  - fix(http): nest the MCP router under /mcp so its catch-all cannot steal
    REST 404s (unknown paths now return not_found, not 405); apply a 1 MiB
    body limit to the composed app; reject non-loopback peers on both MCP and
    REST (IpFilter allow-list 127.0.0.1/::1 plus ConnectInfo middleware).
  - fix(bus): register lookup uses EXISTS instead of loading the whole roster;
    sqlite errors are traced; deregister deletes inbox+roster in one
    transaction; list_agents/stats fail shutting_down after close.
  - fix(launchd): plist ProgramArguments exec the release binary directly

    machine.
  - test(core): 35-test suite green — bus behavior incl. waiter races,
